= SyncTERM emulation manuals
:toc:

These manuals describe the input, output and compatibility behavior implemented
by SyncTERM. They are references for BBS authors and terminal users. The
`*_CONFORMANCE.md` documents record evidence and test coverage; the
`*_IMPLEMENTATION.adoc` documents retain implementation decisions and history.

== Choosing an emulation

Screen Mode selects the base text emulation and its initial geometry. Graphics
selects an additional protocol parser. Encoding selects the interpretation of
ordinary text; it does not translate command bytes or binary payloads.

== Notation

`ESC` means byte `0x1B`, `CSI` means `ESC [` unless stated otherwise, `CR`
means `0x0D`, and `LF` means `0x0A`. Hexadecimal values describe bytes, not
Unicode code points. Spaces inserted between bytes in explanatory notation
are not sent unless explicitly required by the protocol.

Coordinates are zero-based unless a command says otherwise. Parameters named
`x,y` are numbers to supply; they are not literal characters. Examples in
code blocks show the printable part of the stream. An `ESC` in a block must
be replaced by the actual escape byte when transmitting it.

Commands and payloads can span receive buffers. A TCP packet boundary is not
a command terminator. Counted binary payloads belong entirely to their
protocol until their count is exhausted, even when they contain escape bytes,
newlines, attention prefixes or text terminators.

== Shared behavior and boundaries

Text emulations share SyncTERM's text placement, history, logging and session
lifecycle. A raw capture preserves connection bytes; text capture observes
decoded text and omits opaque payloads. Local UI and the optional status bar
have their own fonts and geometry. Remote palette/font changes do not redefine
the local menus.

The graphics manuals distinguish graphical text from console text, physical
palette indices from logical pens, and graphics points from text cursors.
Selecting a font or encoding does not make those objects interchangeable.
Audio commands still consume their input and advance their protocol state
when physical playback is disabled. Reset and disconnect cancel pending
input, local waits and session-owned playback.

See link:Manual.txt[the user manual] for connection setup and local keys,
link:Console.adoc[the console interface] for rendering, and
link:UnicodeBoundary.adoc[the Unicode boundary] for text conversion.

== Maintaining these references

Update the corresponding manual when changing a command, reply, default,
reset rule, encoding rule or compatibility exception. Document current
observable behavior, and identify an unsupported operation explicitly.
An available font file, decoder or rendering primitive alone does not establish
that its wire command is implemented. Keep evidence and independent test
coverage in the existing conformance inventories.
