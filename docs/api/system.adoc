[[api-system]]
== System services and portability

These APIs isolate the POSIX/Windows split and expose UTF-8 paths, portable
time and synchronization, and opaque native resources.  Platform selection is
made by CMake; callers do not branch on compiler identity.

=== Time and paths

[cols="2m,2m,5"]
|===
| Target | Header | Contract

| `st_time`
| link:time/st_time.h[st_time.h]
| Monotonic millisecond/nanosecond clocks, relative monotonic deadlines, and
absolute `TIME_UTC` deadlines for condition variables.  `-1` means infinity
where documented.  Keep elapsed-time decisions on the monotonic clock; use the
UTC helper only to satisfy the condition-variable interface.  Tests: `time`
and `time_fault`.

| `syncterm_path`
| link:path/path.h[path.h]
| Pure native-path parsing plus allocated join, parent, separator, absolute,
and user-expansion operations.  Functions returning `ptrdiff_t` report the
required byte count or a negative `IO_ERROR_*`; undersized buffers are
unchanged and exact in-place use is supported.  Use the “untrusted” helpers
for names received from another system because they reject both separator
styles, dot, and dot-dot.  Test: `path`.

| `st_app_paths`
| link:app_paths/st_app_paths.h[st_app_paths.h]
| Resolves all per-user configuration, cache, download, script, theme, and key
locations, with optional borrowed overrides.  The resulting strings are owned
by `struct st_app_paths` until `st_app_paths_dispose()`.  `prepare_*` creates
only the parent needed for the selected output.  Tests: `app_paths` and, on
POSIX, `app_paths_xdg`.

| `st_windows_utf` (Windows)
| link:windows_utf/st_windows_utf.h[st_windows_utf.h]
| The strict UTF-8/UTF-16 allocation boundary used by Windows mechanisms.  It
is documented with the text APIs in <<api-foundation>>.
|===

=== Files and runtime loading

[cols="2m,2m,5"]
|===
| Target | Header | Contract

| `syncterm_filesystem`
| link:filesystem/filesystem.h[filesystem.h]
| UTF-8 metadata, stream, directory, removal, rename, copy, and replacement
operations.  Metadata distinguishes following a final link from inspecting
the link itself.  `fs_replace_file()` writes and closes a sibling temporary
before atomic replacement; `fs_copy_file()` preserves permission mode and
modification time.  Stream offsets and sizes are 64-bit and do not rely on
`long`.  Test: `filesystem`.

| `syncterm_file_map`
| link:file_map/file_map.h[file_map.h]
| Immutable whole-file byte views.  A successful empty mapping still has a
non-NULL data pointer.  The source file must not be concurrently changed or
truncated.  `file_map_open_stream()` borrows the stream only during the call
and preserves its position; pending writes must already be flushed.  Close
consumes the map.  Test: `file_map`.

| `st_file_lock`
| link:file_lock/st_file_lock.h[st_file_lock.h]
| Blocking shared/exclusive advisory locks on a persistent `<path>.lock`
sidecar.  Keep the lock for the entire read/merge/write transaction and release
it with `st_file_lock_release()`.  Tests: `file_lock` and `file_lock_error`.

| `syncterm_dynamic_library`
| link:dynamic_library/dynamic_library.h[dynamic_library.h]
| Loads a library by safe ASCII filename fragments and descending supported
major versions, with local or global symbol visibility.  It does not accept an
arbitrary path.  Symbol pointers are borrowed until close; the caller casts
them to the declaration used by the complete capability probe.  Close consumes
the handle even if native cleanup fails.  Test: `dynamic_library`.
|===

=== Threads and synchronization

`syncterm_threads` is the project-owned C11-equivalent namespace.  Never expose
or alias `thrd_*`, `mtx_*`, `cnd_*`, or `tss_*`.  CMake prefers a complete
pthreads contract, including winpthreads under MinGW, and otherwise uses the
Win32 implementation on Windows.

[cols="2m,2m,5"]
|===
| Target | Header | Contract

| `syncterm_threads`
| link:threads/st_threads.h[st_threads.h]
| Threads, plain/recursive/timed mutexes, condition variables, once flags,
thread-local storage, sleep/yield, and reader/writer locks.  Operations return
`ST_THREAD_*`, not `IO_ERROR_*`.  Condition waits release and reacquire the
mutex and must always sit inside a predicate loop.  Read locks are recursive;
write locks and read-to-write upgrades are not.  Join every joinable thread or
explicitly detach it.  Test: `st_threads`.

| `syncterm_event`
| link:event/st_event.h[st_event.h]
| Heap-owned binary auto-reset or manual-reset events built on
`st_threads`.  Wait functions use `ST_THREAD_*`; timed waits take an absolute
deadline.  No operation or waiter may remain active at destruction.  Test:
`st_event`.

| `syncterm_semaphore`
| link:semaphore/st_semaphore.h[st_semaphore.h]
| Heap-owned bounded counting semaphores.  Posting at the configured maximum
fails without changing the count.  As with events, timed waits use absolute
deadlines and destruction requires external quiescence.  Test: `st_semaphore`.
|===

Atomics are appropriate only for genuinely atomic state, not as a shortcut
around a mutex-protected invariant.  Every worker-owning component must define
who starts it, the stop predicate, the synchronization protecting that
predicate, and who joins it.
