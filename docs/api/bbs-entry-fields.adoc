[[bbs-entry-fields]]
=== BBS entry field coverage

The INI codec covers 53 canonical keys and 59 profile members. `bbs_list`
tests default and non-default encode/decode values for every persisted member,
including full-width BPS/call counters, optional paths, palettes and fingerprints.
Six metadata/derived members below are not additional INI keys.

`WrenScripts` items are ASCII-whitespace-trimmed, validated basenames (1..255
ASCII letters/digits/underscores), deduplicated in first-occurrence order, and
limited to 1023 serialized bytes. Reserved menu/bootstrap module names are
rejected. Invalid stored lists are ignored; invalid Wren assignments leave the
previous list intact. Names have no `.wren` suffix.

SkyPix uses ScreenMode as its pixel canvas and Encoding as its wire encoding.
Selecting SkyPix initially chooses Amiga640x200 (4:3) and Latin-1; both remain
editable. Amiga640x400 supplies a taller 4:3 canvas with an 80×50 system grid
of 8×8 cells. AmigaFont/AmigaFontSize select an installed or bundled native strike
for initial text and reset, with unchanged pixel metrics in either Amiga mode.
The system cell grid is independent of the strike; graphics clip to its drawable area.
`NoStatus=false` reserves the last system-cell row within the selected mode;
resolution and aspect ratio remain unchanged. Ordinary Font
preferences remain available for other graphics modes. Application UI uses the
system CP437 font, independently of the connection's font. The Graphics selector
offers Off, RIP v1, RIP v3, SkyPix (Kick 1.3) and SkyPix (Kick 3.1).

`Graphics` is canonical. Legacy `RIP` is read only when Graphics is absent;
saving removes RIP after writing Graphics.

Saving an affected entry or defaults materializes canonical ConnectionType and
ProtocolLogLevel values before removing BeDumb and TelnetLogLevel aliases.
Unrelated keys/sections and concurrent field edits remain intact.

Statistics are recorded once after transport establishment, before connected
scripts. The locked transaction increments the latest stored count rather than
overwriting it from a stale menu snapshot. A system/web entry is copied to the
personal directory on its first successful connection; its source is untouched.
Quick connections are not persisted. Safe mode updates only the active profile,
opening no log file and writing no directory. Write failures are nonfatal
diagnostics, with no new blocking dialogs.

`app_session_mode` exercises INI -> real application PTY session -> connected
Wren/CTerm -> log/statistics -> reload. `wren_bbs-setters` exercises menu
save/reload, script validation, GHost and BPS persistence. `cterm` and
`screen_mode` cover palette families and reset semantics; `term` checks response
suppression independently of user input. `connection_shell_codec` checks
incremental conversion and partial I/O on every platform;
`connection_conpty_encoding` exercises Wide Console input/output in native
Windows CI (not Wine).
