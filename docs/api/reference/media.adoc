[[reference-media]]
=== Media and console API reference

==== Audio mixer

Mixer input/output is interleaved native-endian signed 16-bit stereo.  Counts
are frames.  Mixer buffer options apply per queued buffer; stream volume applies
to the complete stream.

[source,c]
----
int audio_mixer_create(audio_mixer_t **result);
void audio_mixer_destroy(audio_mixer_t *mixer);
int audio_mixer_stream_create(audio_mixer_stream_t **result,
    audio_mixer_t *mixer, float volume_left_db, float volume_right_db);
void audio_mixer_stream_destroy(audio_mixer_stream_t *stream);
int audio_mixer_stream_append(audio_mixer_stream_t *stream,
    const int16_t *frames, size_t frame_count,
    const struct audio_mixer_buffer_options *options);
int audio_mixer_stream_append_take(audio_mixer_stream_t *stream,
    int16_t *frames, size_t frame_count,
    const struct audio_mixer_buffer_options *options);
int audio_mixer_stream_clear(audio_mixer_stream_t *stream);
int audio_mixer_stream_drain(audio_mixer_stream_t *stream);
bool audio_mixer_stream_is_idle(audio_mixer_stream_t *stream);
int audio_mixer_stream_set_volume(audio_mixer_stream_t *, float, float);
int audio_mixer_stream_ramp_volume(audio_mixer_stream_t *, float, float,
    size_t frame_count);
int audio_mixer_stream_get_volume(audio_mixer_stream_t *, float *, float *);
size_t audio_mixer_pull(audio_mixer_t *, int16_t *output, size_t frame_count);
size_t audio_mixer_pull_pending(audio_mixer_t *, int16_t *output,
    size_t frame_count, uint64_t *ticket);
void audio_mixer_acknowledge(audio_mixer_t *, uint64_t ticket);
int audio_mixer_wait_for_data(audio_mixer_t *);
void audio_mixer_stop(audio_mixer_t *, int status);
----

Create outputs and live object pointers are required.  Frame arrays are
borrowed by append and conditionally consumed by append-take; NULL is valid only
at zero frames.  Options are borrowed and required.  dB output pointers and
pull ticket are required.  Status calls return zero/negative `IO_ERROR_*`;
pull returns the non-silent prefix count.  The mixer synchronizes stream work,
but destruction still requires external quiescence.

[cols="3m,7"]
|===
| Function group | Parameters, result, and effect

| audio_mixer_create(result), audio_mixer_destroy(mixer)
| Allocate/free a mixer and any remaining streams/queues.

| audio_mixer_stream_create(result, mixer, left_db, right_db)
| Adds an owned stream with initial channel gains.

| audio_mixer_stream_destroy(stream)
| Removes a stream and discards its queued audio; do not race stream calls.

| audio_mixer_stream_append(stream, frames, count, options)
| Copies and queues frames.

| audio_mixer_stream_append_take(stream, frames, count, options)
| Queues caller allocation and takes ownership only on success.

| audio_mixer_stream_clear(stream)
| Discards queued/not-yet-acknowledged playback and cancels affected drain.

| audio_mixer_stream_drain(stream)
| Waits for the queue present at entry; an unterminated loop is busy.

| audio_mixer_stream_is_idle(stream)
| Reports no queued or backend-pending frames for the stream.

| audio_mixer_stream_set_volume(stream, left_db, right_db), audio_mixer_stream_ramp_volume(stream, left_db, right_db, frame_count), audio_mixer_stream_get_volume(stream, left_db, right_db)
| Set immediately, interpolate over a frame count, or query channel dB gains.

| audio_mixer_pull(mixer, output, frame_count)
| Fills every requested frame and returns the non-silent prefix length.

| audio_mixer_pull_pending(mixer, output, frame_count, ticket)
| Pulls for a blocking backend and issues an acknowledgment ticket.

| audio_mixer_acknowledge(mixer, ticket)
| Marks ticketed frames accepted by the device so drain can progress.

| audio_mixer_wait_for_data(mixer)
| Blocks a backend worker until data or stop.

| audio_mixer_stop(mixer, status)
| Wakes workers/drains and makes the supplied status terminal.
|===

==== Audio engine

All public PCM is `AUDIO_SAMPLE_RATE` (44100 Hz), two-channel, native-endian
`int16_t`.  Volumes range from -192 through +96 dB.

[source,c]
----
uint32_t audio_available_backends(void);
uint32_t audio_compiled_backends(void);
int audio_engine_create(audio_engine_t **result, uint32_t allowed_backends);
void audio_engine_destroy(audio_engine_t *engine);
enum audio_backend audio_engine_backend(const audio_engine_t *engine);
int audio_stream_create(audio_stream_t **result, audio_engine_t *engine,
    float volume_left_db, float volume_right_db);
void audio_stream_destroy(audio_stream_t *stream);
int audio_stream_append(audio_stream_t *, const int16_t *frames,
    size_t frame_count, const struct audio_buffer_options *options);
int audio_stream_append_take(audio_stream_t *, int16_t *frames,
    size_t frame_count, const struct audio_buffer_options *options);
int audio_stream_append_u8_mono_22050(audio_stream_t *, const uint8_t *samples,
    size_t sample_count, const struct audio_buffer_options *options);
int audio_stream_clear(audio_stream_t *);
int audio_stream_drain(audio_stream_t *);
bool audio_stream_is_idle(audio_stream_t *);
int audio_stream_set_volume(audio_stream_t *, float, float);
int audio_stream_ramp_volume(audio_stream_t *, float, float, size_t);
int audio_stream_get_volume(audio_stream_t *, float *, float *);
int audio_engine_play(audio_engine_t *, const int16_t *, size_t,
    const struct audio_buffer_options *);
int audio_engine_play_u8_mono_22050(audio_engine_t *, const uint8_t *, size_t,
    const struct audio_buffer_options *);
int audio_generate_tone(int16_t *result, size_t frame_count,
    double frequency, enum audio_wave_shape shape, bool clean_edges);
int audio_beep(audio_engine_t *, double frequency, uint32_t duration_ms);
int st_audio_runtime_create(st_audio_runtime_t **result, uint32_t allowed);
void st_audio_runtime_destroy(st_audio_runtime_t *runtime);
void st_audio_runtime_set_allowed(st_audio_runtime_t *, uint32_t allowed);
uint32_t st_audio_runtime_allowed(st_audio_runtime_t *);
int st_audio_runtime_acquire(st_audio_runtime_t *, audio_engine_t **result);
----

Engine/stream create outputs are required and unchanged on negative
`IO_ERROR_*`.  Buffers/options are borrowed except append-take's conditional
transfer.  Counts are frames/samples, never bytes.  Gain values must be finite
and in range.  Stream methods synchronize concurrent operations, but callers
must stop them before stream/engine destruction.  Runtime acquire returns a
borrowed engine, not a new ownership reference.

[cols="3m,7"]
|===
| Function group | Parameters, result, and effect

| audio_compiled_backends(), audio_available_backends()
| Return candidate masks before or after probing runtime-loadable libraries.

| audio_engine_create(result, allowed_backends)
| Opens the first usable allowed backend in documented preference order.  Only
one engine may exist per process.

| audio_engine_destroy(engine)
| Stops workers/callbacks, destroys remaining streams, and frees the engine.

| audio_engine_backend(engine)
| Returns the selected single backend bit.

| audio_stream_create(result, engine, left_db, right_db), audio_stream_destroy(stream)
| Add/remove an independently queued stream owned by the engine.

| audio_stream_append(stream, frames, frame_count, options), audio_stream_append_take(stream, frames, frame_count, options)
| Copy or conditionally take ownership of fixed-format frames and queue
per-buffer fade/crossfade/loop policy.

| audio_stream_append_u8_mono_22050(stream, samples, sample_count, options)
| Converts/copies legacy unsigned 8-bit 22050 Hz mono samples before queuing.

| audio_stream_clear(stream), audio_stream_drain(stream), audio_stream_is_idle(stream)
| Cancel queued work, wait for the entry snapshot, or query completion.

| audio_stream_set_volume(stream, left_db, right_db), audio_stream_ramp_volume(stream, left_db, right_db, frame_count), audio_stream_get_volume(stream, left_db, right_db)
| Immediate/ramped/query stream gain.

| audio_engine_play(engine, frames, frame_count, options), audio_engine_play_u8_mono_22050(engine, samples, sample_count, options)
| Queue a copied one-shot.  Looping is rejected because no stream handle would
exist to stop it.

| audio_generate_tone(result, frame_count, frequency, shape, clean_edges)
| Fills fixed-format stereo samples for the selected waveform.

| audio_beep(engine, frequency, duration_ms)
| Synchronously plays the historical beep, using speaker fallback as needed.

| st_audio_runtime_create(result, allowed), st_audio_runtime_destroy(runtime)
| Manage application-lifetime lazy engine state and synchronization.

| st_audio_runtime_set_allowed(runtime, allowed), st_audio_runtime_allowed(runtime)
| Set/query the mask used only when an engine has not yet been created.

| st_audio_runtime_acquire(runtime, result)
| Lazily creates and returns a borrowed engine valid through runtime destroy.
|===

[source,c]
----

    uint32_t height);
void st_rgb_buffer_destroy(struct st_rgb_buffer *buffer);
int st_pixel_mask_create(struct st_pixel_mask **result, uint32_t width,
    uint32_t height);
int st_pixel_mask_get(const struct st_pixel_mask *, uint32_t x, uint32_t y,
    bool *value);
int st_pixel_mask_set(struct st_pixel_mask *, uint32_t x, uint32_t y,
    bool value);
void st_pixel_mask_destroy(struct st_pixel_mask *mask);
int st_pixel_buffer_fill(struct st_pixel_buffer *, uint32_t primary,
    uint32_t alternate);
int st_pixel_scaler_create(st_pixel_scaler_t **result);
void st_pixel_scaler_destroy(st_pixel_scaler_t *scaler);
int st_pixel_scaler_scale(st_pixel_scaler_t *,
    const struct st_rgb_buffer **result, const struct st_rgb_buffer *source,
    uint32_t width, uint32_t height, enum st_pixel_scaling_policy policy);
int st_pixel_scaler_scale_region(st_pixel_scaler_t *,
    const struct st_rgb_buffer **result, const struct st_rgb_buffer *source,
    const struct st_pixel_rect *damage, struct st_pixel_rect *output_damage);
int st_pixel_buffer_blit(struct st_pixel_buffer *destination,
    const struct st_pixel_buffer *source, const struct st_pixel_mask *mask,
    const struct st_pixel_blit *blit);
----

Create/clone outputs are required owned handles, unchanged on negative
`IO_ERROR_*`; dimensions must be nonzero and multiplication representable.
Mask coordinates must be in bounds.  Scale result is a required borrowed-view
output, source/damage are borrowed, and output damage is required.  Blit
destination is mutable, source/blit are required borrowed inputs, mask may be
NULL, scale factors must be nonzero, and failure occurs before partial change.

[cols="3m,7"]
|===
| Function group | Parameters, result, and effect

| st_pixel_buffer_create(result, width, height, alternate)
| Allocates a nonempty zeroed native-colour buffer and optional blink plane.

| st_pixel_buffer_clone(result, source)
| Deep-copies dimensions and present planes.

| st_pixel_buffer_ensure_alternate(buffer)
| Allocates the alternate plane initialized from primary before publishing it.

| st_pixel_buffer_remove_alternate(buffer), st_pixel_buffer_destroy(buffer)
| Remove one plane or free the complete buffer.

| st_rgb_buffer_create(result, width, height), st_rgb_buffer_destroy(buffer)
| Allocate/free a nonempty zeroed packed-`0x00RRGGBB` image.

| st_pixel_mask_create(result, width, height), st_pixel_mask_destroy(mask)
| Allocate/free a zeroed contiguous MSB-first bit mask.

| st_pixel_mask_get(mask, x, y, value), st_pixel_mask_set(mask, x, y, value)
| Bounds-checked bit access.

| st_pixel_buffer_fill(buffer, primary, alternate)
| Fills existing planes with native palette-index/tagged-RGB values.

| st_pixel_buffer_blit(destination, source, mask, blit)
| Clips and integer-scales the selected source rectangle, optional mask and
flips.  Self-blit has source-snapshot semantics; alternate source content is
preserved.

| st_pixel_scaler_create(result), st_pixel_scaler_destroy(scaler)
| Allocate/free a persistent scaling plan and retained intermediate images.

| st_pixel_scaler_scale(scaler, result, source, width, height, policy)
| Plans/scales a complete RGB image at same size or larger.  Returns a borrowed
buffer until the next scale/destruction.

| st_pixel_scaler_scale_region(scaler, result, source, damage, output_damage)
| Updates a prior plan after source damage and reports expanded final damage.
|===

==== External image decoding

[source,c]
----
int st_pixel_image_decode_ppm(struct st_pixel_buffer **result,
    const void *data, size_t length);
int st_pixel_image_decode_pbm(struct st_pixel_mask **result,
    const void *data, size_t length);
bool st_pixel_image_jxl_supported(void);
int st_pixel_image_decode_jxl(struct st_pixel_buffer **result,
    const void *data, size_t length);
----

`data` is a borrowed counted byte span, NULL only for zero length.  Output
handles are required and unchanged on negative `IO_ERROR_*`; success transfers
ownership to the caller and the corresponding pixels destructor.  Decoders
reject malformed dimensions, arithmetic overflow, truncation, and trailing
format violations rather than returning a partial image.

[cols="3m,7"]
|===
| Function | Parameters, result, and effect

| st_pixel_image_decode_ppm(result, data, length)
| Strictly decodes counted PPM bytes into an owned tagged-RGB pixel buffer.

| st_pixel_image_decode_pbm(result, data, length)
| Strictly decodes counted PBM bytes into an owned bit mask.

| st_pixel_image_jxl_supported()
| Reports whether the optional runtime JPEG XL decoder is usable.

| st_pixel_image_decode_jxl(result, data, length)
| Decodes to an owned pixel buffer or returns `IO_ERROR_NOT_SUPPORTED` when
unavailable.  Every decoder preserves `result` on failure.
|===

==== Font catalogs

[source,c]
----
size_t st_builtin_font_count(void);
const char *st_builtin_font_name(size_t selector);
bool st_builtin_font_broken_vertical(size_t selector);
enum st_codepage st_builtin_font_codepage(size_t selector);
bool st_builtin_font_get(size_t selector, uint32_t width, uint32_t height,
    struct st_console_font *font);
int st_presentation_font_create(struct st_presentation_font *result,
    const struct st_console_font *base);
void st_presentation_font_destroy(struct st_presentation_font *font);
extern const struct st_console_font st_unscii_8_font;
extern const struct st_console_font st_unscii_16_font;
extern const struct st_console_font st_unifont_font;
----

Selectors must be below `st_builtin_font_count()`.  Static names/font storage
are borrowed for process lifetime.  `st_builtin_font_get` writes a required
descriptor only on true, and that descriptor borrows catalog storage.
Presentation result is caller storage which owns allocations only after zero
return and must then be destroyed once; `base` is borrowed during creation.

[cols="3m,7"]
|===
| Function or object | Parameters, result, and effect

| st_builtin_font_count(), st_builtin_font_name(selector)
| Iterate static legacy selector names; invalid selector name is NULL.

| st_builtin_font_broken_vertical(selector), st_builtin_font_codepage(selector)
| Query rendering repair and source codepage metadata.

| st_builtin_font_get(selector, width, height, font)
| Copies a console-font descriptor borrowing process-lifetime bitmap/mapping
storage; requires exact supported cell dimensions.

| st_presentation_font_create(result, base), st_presentation_font_destroy(font)
| Build/free an owned augmented fallback-font descriptor.

| st_unscii_8_font, st_unscii_16_font, st_unifont_font
| Process-lifetime static `st_console_font` objects; Unifont exists only in the
optional target.
|===

----
Every console/display/snapshot pointer must refer to a live object of that
kind, except where a destructor explicitly accepts NULL.  Configuration,
rectangle, cell, font, event, pixel, title, and URL inputs are borrowed for the
call unless registration says static lifetime or copy.  Result/output pointers
are required unless the declaration's contract says optional and are unchanged
on negative `IO_ERROR_*`.  Owned text/pixel/snapshot results must use the
component's matching destructor.  Coordinates and rectangles are zero-based,
nonempty where required, and checked against current dimensions.  Public calls
may run concurrently on a live console, but owners must quiesce all calls before
destroying a console or its display.
