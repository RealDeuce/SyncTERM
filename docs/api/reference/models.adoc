[[reference-models]]
=== Model API reference

==== INI documents

An `ini_document_t` owns physical section blocks, records, comments, and
values.  An `ini_section_t` is a borrowed view into that document.  Any
document mutation invalidates all previously returned sections, pairs, and
string views.  A NULL `ini_write_style` selects `ini_default_style` where the
setter permits it.

Document/section pointers must belong to the same live document.  Names, keys,
values, styles, enum/bit tables, and input arrays are borrowed for the call.
Create/clone/parse/read and allocated-list outputs are required in/out handles
replaced only on zero `IO_ERROR_*` status.  Getters return defaults rather than
errors; successful setters invalidate every borrowed document view.

==== Profiles

[source,c]
----
uint16_t st_connection_default_port(enum st_connection_type type);
void st_profile_init(struct st_profile *profile);
void st_profile_dispose(struct st_profile *profile);
bool st_profile_copy(struct st_profile *result,
    const struct st_profile *source);
const char *st_profile_ghost_program(const struct st_profile *profile);
bool st_profile_script_name_valid(const char *name, size_t length);
bool st_profile_scripts_append(char *scripts, const char *name, size_t length);
bool st_profile_scripts_parse(char *result, const char *input);
----

Profile pointers address caller storage.  Initialize before copy/field use and
dispose afterward.  Copy requires an initialized destination, deep-copies owned
paths, and returns false without changing it.  Default-port is pure and returns
zero for invalid/non-network types.

`st_profile_init(profile)` establishes defaults and owned fields;
`encoding` defaults to CP437 and stores a canonical `st_codepage` value or
`ST_PROFILE_ENCODING_UTF8`. The BBS INI `Encoding` key uses canonical names;
missing keys infer the encoding from the saved built-in font, falling back to
CP437 for unknown or custom fonts. This rule is independent of transport and
screen mode; Shell does not imply UTF-8. An explicit valid `Encoding` wins.
Saving an existing entry or defaults writes that inferred encoding explicitly,
so changing transport or font does not silently change the encoding on reload.
`st_profile_dispose(profile)` frees its owned optional paths.  Call
`st_profile_copy(result, source)` only with an initialized destination; it
deep-copies owned fields and preserves the old destination on failure.
Identifiers default to -1; the menu assigns distinct saved-entry identifiers.
`st_profile_ghost_program()` returns a borrowed transient URL override or the
Password value for GHost (otherwise an empty string).
`st_profile_script_name_valid()` checks a counted basename.
`st_profile_scripts_append()` requires a canonical list in a 1024-byte buffer
and appends only new valid names. `st_profile_scripts_parse()` requires a
1024-byte result and NUL-terminated input; it trims, validates and deduplicates
items. Both leave the destination unchanged on failure. Parsing supports
input/output aliasing; empty input produces an empty list.
`st_connection_default_port(type)` returns the inherent network port or zero
for transports without one.

Enumeration values stored in files or exposed to Wren—especially connection
type and screen mode—are compatibility values and must not be renumbered.

Caller-owned settings/draft structs require init before use and dispose after.
The global store functions are process-wide and caller-serialized.  Strings
passed to mutators are borrowed and copied.  `*_at` pointers are borrowed until
the next mutation/reload/shutdown.  Indexes must be in range (insert permits
the documented end position); status functions return zero/negative
`IO_ERROR_*`.  Save failure preserves installed state and merge baseline.

Manager/prepared output handles are required and installed/consumed as named.
Paths/settings, filenames, and packages are borrowed; manager copies retained
data.  Optional error/warning buffers may be NULL only with size zero and are
best-effort diagnostics, while the integer return is authoritative
zero/negative `IO_ERROR_*`.  Catalog/theme rows and strings are borrowed and
invalidation-scoped as detailed below.  No manager operation is implicitly
safe to race another; the owner serializes it.

Open output handles are required and unchanged on negative `IO_ERROR_*`
failure; close consumes and accepts only a live object.  Paths/settings,
profiles, names, field arrays, progress callbacks, and contexts are borrowed.
Password is a counted secret copied by successful open and cleared on close.
Mutation result is optional; when supplied, its `cache_status` is secondary to
the primary integer status.  Every returned entry/profile/diagnostic/info
pointer is borrowed until the next successful rebuild/mutation.  Callers
serialize all access to one list.
Each entry's `name_key` and `name_key_size` expose the retained NFD caseless
form of its name.  The bytes are borrowed with the entry, including for a
shadowed entry.

Static screen descriptors are borrowed; custom/palette result buffers are
required caller storage.  History create installs ownership on zero, publish
borrows and copies `width * lines` cells, and copy installs a malloc-owned cell
array plus required metadata outputs.  Hyperlink add borrows counted spans
(`parameter == NULL` only at zero length), copies them, and writes a required
nonzero ID.  Copy produces owned strings disposed by `st_hyperlink_dispose`.
Root callbacks receive a marker and must report every live ID without calling
back into the registry; they and their contexts remain borrowed until
unregistered. Collection is automatic only when all IDs are occupied, or may
be requested explicitly. A failed root callback aborts collection without
reclaiming entries. All status functions return zero/negative `IO_ERROR_*`.
