=== Terminal API reference

==== Font catalog

[source,c]
----
int st_font_catalog_create(st_font_catalog_t **result, st_console_t *console);
void st_font_catalog_destroy(st_font_catalog_t *catalog);
int st_font_catalog_load_custom(st_font_catalog_t *catalog, uint8_t selector,
    const char *path);
int st_font_catalog_register_custom(st_console_t *console, const char *path,
    uint16_t *identifier);
bool st_font_catalog_identifier(const st_font_catalog_t *catalog,
    uint8_t selector, uint16_t *identifier);
bool st_font_catalog_selector(const st_font_catalog_t *catalog,
    uint16_t identifier, uint8_t *selector);
enum st_codepage st_font_catalog_codepage(const st_font_catalog_t *catalog,
    uint8_t selector);
st_console_t *st_font_catalog_console(const st_font_catalog_t *catalog);
----

[cols="3m,7"]
|===
| Function | Parameters, result, constraints, and ownership

| st_font_catalog_create(result, console)
| `result` and `console` are required.  Registers compatible built-ins and
allocates selector state; zero succeeds, negative `IO_ERROR_*` fails with
`result` unchanged.  The console is borrowed and must outlive the catalog.

| st_font_catalog_destroy(catalog)
| Frees selector state; NULL is accepted.  Registered console fonts remain.

| st_font_catalog_load_custom(catalog, selector, path)
| Requires selector 46 or greater and a non-NULL path.  The file must contain
exactly 256 glyphs at the console cell dimensions.  On success replaces that
selector and returns zero; on failure its old mapping is unchanged.

| st_font_catalog_register_custom(console, path, identifier)
| Registers the same exact-size custom-font format without a catalog mapping.
Writes the console-owned identifier only on success.  This is for hosts which
own their own selector table.

| st_font_catalog_identifier(catalog, selector, identifier)
| Returns true and writes the identifier when the selector is registered;
otherwise returns false and leaves output unspecified.

| st_font_catalog_selector(catalog, identifier, selector)
| Reverse lookup.  Returns true only for the catalog's current mapping.

| st_font_catalog_codepage(catalog, selector)
| Returns the built-in selector's semantic codepage; selectors 46 and above
use CP437.  This query does not assert that the selector is registered.

| st_font_catalog_console(catalog)
| Returns the borrowed console, or NULL for a NULL catalog.
|===

==== CTerm

`struct st_cterm_config` borrows every pointer through terminal destruction.
`status_line` initially selects the DEC indicator status display and reserves
one console row for it. `terminal_rows == 0` selects every row not occupied by
that status display; otherwise the difference remains reserved for the caller.
The terminal and optional status row must fit the console.
`scrollback_lines` is bounded by addressable allocation size.
`expand_lf` enables the parser's LF-as-CR+LF policy; false (the default)
retains the column on LF. This local policy survives terminal resets, does not
add a second line advance to CR+LF input, and emits no output bytes.
The font selector must be registered in the supplied catalog, and that catalog
must belong to the supplied console. Geometry must fit the parser's signed
coordinate representation. `palette_mapping`, when non-NULL, points to 16
borrowed canonical palette indices copied during creation. `petscii_machine`
selects C64, C128 40-column, or C128 80-column semantics for PETSCII.
`rip_version` is `ST_CTERM_RIP_OFF` (the zero/default value),
`ST_CTERM_RIP_1`, or `ST_CTERM_RIP_3`. RIP requires ANSI-BBS and a bitmap
console of at least 640×350 pixels; its drawing canvas is the upper-left
640×350 pixels. Creation enables full-surface scrolling on that console and
destruction restores text-only scrolling. `rip_directory`, when non-NULL, is
a borrowed per-BBS directory for RIP scene, icon, and variable files; its
path must remain valid for the terminal lifetime. A NULL `rip_prompt` leaves
interactive `RIP_DEFINE` variables unchanged. Otherwise the callback runs
synchronously with the prompt text, initial value, maximum character count,
and `reject_blank` flag. It returns zero with a NULL `*result` to cancel, or
zero with a `malloc`-owned string to accept; a nonzero result reports an error.
`rip_prompt_context` is passed to that callback unchanged.

`apc_directory` enables built-in APC handling independently of `rip_version`.
It is a borrowed UTF-8 per-BBS cache path, valid through destruction; NULL
leaves APC handling to `apc`/`apc_context`. CTerm creates the directory on use
and confines remote paths to it, rejecting traversal, links, and platform
device names. Failure to initialize the cache silently consumes APCs, as in
v1.10a. `application_version` is a borrowed NUL-terminated string used verbatim
in `SyncTERM:VER` replies; NULL suppresses that reply. The application must
supply a protocol-safe string without embedded controls. Recognized built-in
commands consume the APC; unknown ones reach the existing synchronous `apc`
callback. All response bytes use `output` with origin `ST_CTERM_OUTPUT_RESPONSE`.
APC buffers, masks, patches, and dedicated audio streams are terminal-owned;
they survive resets and are released on destruction. Registered font bitmaps
are copied into, and owned by, the console.

`$SBARON$` changes the reserved status row, but the connected-session
contents of that row belong to the Wren application UI, not RIP drawing.
The minimal terminal session does not render those contents; their port is
deferred with the connected Wren UI.
RIP modem-transfer execution is also deferred.

[cols="3m,7"]
|===
| Function | Parameters, result, constraints, and effect

| st_cterm_create(result, config)
| Allocates and resets terminal/parser state and its optional scrollback.
Returns zero or negative `IO_ERROR_*`; `result` is unchanged on failure.
UTF-8 is valid only for ANSI-BBS and Atari-ST VT52.

| st_cterm_destroy(terminal_ptr)
| Finishes streams, destroys a status subterminal, frees scrollback/parser
state, and sets the caller handle to NULL.  NULL pointer/value is accepted.

| st_cterm_write(terminal, bytes, size, consumed)
| Incrementally consumes borrowed wire bytes.  `consumed` is required and is
always written.  A successful return consumes all bytes; on callback/render
failure it identifies the resume offset.  A call boundary is not EOF.

| st_cterm_finish(terminal)
| Dispatches a pending RIP command at end of stream, commits a pending
grapheme, and reports an incomplete UTF-8 prefix once as a decode error.
Safe to call again without duplicating the command or error.

| st_cterm_poll(terminal)
| On the terminal owner thread, checks armed audio channels and sends one
idle report after an observed running-to-stopped transition. Idle-at-arm is
not immediate completion. Call repeatedly even with no incoming bytes; it
does not finish input or block for playback. Returns zero for a live terminal,
`IO_ERROR_INVALID_ARGUMENT` for NULL. Serialize with writes, reset, resize,
and destruction; callbacks run synchronously and must not reenter CTerm.

| st_cterm_prepare_disconnect(terminal)
| After remote teardown only, finishes pending input, resets margins, and
exposes a terminal-style blank bottom row for local chrome. Disables an
indicator/host-writable status row; without one, scrolls once through normal
scrollback so host text is retained. Does not notify the closed peer of the
local geometry change. Returns zero or a negative rendering error.

| st_cterm_reset_terminal(terminal)
| Finishes the RIP and Unicode boundaries, then applies the emulation reset.

| st_cterm_resize(terminal, columns, rows)
| Resizes the underlying console and updates CTerm geometry, margins, cursor
bounds, status subterminal, and scrollback width. Incremental Unicode decoder
and grapheme state remain live across the resize.
Overlapping visible cells and chronological scrollback content are preserved.
The configured count of caller-reserved rows remains fixed; a selected DEC
status display additionally consumes one row. Dimensions must be 1 through
255, and at least one terminal row must remain. Returns zero or `IO_ERROR_*`.

| st_cterm_size(terminal, columns, rows)
| Writes the main terminal's current columns and rows, excluding a status line
and caller-reserved rows. Both output pointers are required. Returns zero or
`IO_ERROR_INVALID_ARGUMENT`.

| st_cterm_encoding(terminal), st_cterm_codepage(terminal)
| Return active policy.  NULL yields CODEPAGE and CP437 defaults respectively.

| st_cterm_set_encoding(terminal, encoding, codepage)
| Finishes pending Unicode before changing policy.  Rejects an invalid enum,
codepage, or UTF-8 with a fixed byte-table emulation.

| st_cterm_copy_history(terminal, cells, columns, rows)
| Allocates a row-major chronological snapshot: staged ring lines then visible
terminal rows.  All outputs are unchanged on failure; caller frees `*cells`.

| st_cterm_handle_key(terminal, key_code, modifiers)
| Encodes one normalized key according to active terminal modes. `modifiers`
is a `ST_CONSOLE_MODIFIER_*` bitmask; RIP uses Shift for reverse tab selection.
Returns true when handled; emitted bytes carry USER origin.

| st_cterm_handle_rip_text(terminal, codepoint)
| Gives a Unicode text-input scalar to RIP's button-hotkey handler before the
session sends it on the wire. Returns true if RIP consumed it. A non-hotkey
must still be sent by the caller through the session's text-output path.

| st_cterm_handle_doorway_key(terminal, scan_code)
| DoorWay scan-code counterpart; returns whether handled.

| st_cterm_handle_physical_keys(terminal, events, count)
| Requires every counted event to be PHYSICAL_KEY.  Updates key-event mode and
returns whether CTerm handled the batch.  The event array is borrowed.

| st_cterm_handle_mouse(terminal, event)
| Requires one MOUSE event.  Applies DEC 9/1000/1002/1003 and encoding modes
1005/1006/1015/1016. With RIP enabled, it also handles mouse regions,
buttons, and click queries in the RIP pixel canvas. Returns true when the
event is consumed or a report, RIP command, or alternate-scroll key emits.

| st_cterm_handle_focus(terminal, focused)
| Emits DEC focus-in/out only while mode 1004 is enabled; return reports emit.
|===

Output/APC/size callbacks are synchronous and must copy borrowed byte/text
spans before returning if they retain them.  CTerm is ordered mutable session
state and is not safe for concurrent calls.

==== Minimal connected session

[source,c]
----
int st_term_connect_profile(st_connection_t **result,
    const struct st_profile *profile, st_console_t *console,
    const struct st_connection_hooks *hooks, struct st_connection_error *error);
enum st_cterm_encoding st_term_profile_encoding(
    const struct st_profile *profile);
enum st_cterm_rip_version st_term_profile_rip_version(
    const struct st_profile *profile);
int st_term_session_create(st_term_session_t **result,
    const struct st_term_config *config);
void st_term_session_destroy(st_term_session_t **session);
int st_term_session_run(st_term_session_t *session,
    enum st_term_disposition *disposition);
int st_term_session_pump(st_term_session_t *session,
    enum st_term_disposition *disposition, bool *finished);
bool st_term_session_remote_closed(const st_term_session_t *session);
int st_term_session_prepare_disconnect(st_term_session_t *session);
int st_term_session_send_text(st_term_session_t *session,
    const char *utf8, size_t size);
int st_term_rip_wire_to_utf8(char *result, size_t capacity,
    size_t *result_size, const uint8_t *wire, size_t size,
    enum st_codepage codepage);
----

[cols="3m,7"]
|===
| Function | Parameters, result, constraints, and effect

| st_term_connect_profile(result, profile, console, hooks, error)
| Reads current console geometry and dispatches Raw, RLogin (both orders),
Telnet, Telnet/TLS, SSH (authenticated or none), GHost, MQTT, Serial (including
three-wire), Modem, or Shell creation. Pointers are borrowed for the call;
connection hooks follow `st_connection` lifetime rules after success.
Unknown types or invalid encodings return `IO_ERROR_INVALID_ARGUMENT`;
encrypted providers unavailable in this build return `IO_ERROR_NOT_SUPPORTED`.
Caller owns the connection.
Shell children receive `MM_CHARSET` set to the profile's encoding name.

| st_term_profile_encoding(profile)
| Returns UTF8 for a profile explicitly configured for UTF-8 and CODEPAGE
otherwise (including NULL). Use this result for the matching session config.

| st_term_profile_rip_version(profile)
| Maps profile RIP version 1 or 3 to the matching CTerm mode. Returns
`ST_CTERM_RIP_OFF` for NULL or any other profile value.

| st_term_session_create(result, config)
| Requires matching non-NULL console, open connection, and font catalog.
Optional audio/hyperlink/history pointers may be NULL.  All configured objects
are borrowed through session destruction.  A visible status row requires at
least two console rows. The connection is updated with the main terminal's
initial cell and pixel geometry, excluding that status row. Result is unchanged
on failure. `rip_version` selects the RIP parser; `rip_directory` and
`rip_prompt`/`rip_prompt_context` have the CTerm lifetime and callback rules
above. For a codepage RIP connection, the session translates incoming wire
bytes to UTF-8 before CTerm and translates outgoing Unicode back to the
configured codepage. CTerm and the RIP parser therefore see Unicode regardless
of the remote wire encoding. `apc_directory` and `application_version` are
forwarded unchanged with the CTerm borrowing rules above, independently of RIP.
`expand_lf` forwards the entry's LF Expand policy unchanged to CTerm; it does
not rewrite wire bytes or the input observed by hooks.

| st_term_session_destroy(session_ptr)
| Finishes RIP and Unicode, publishes history when configured, releases CTerm, and
sets the handle NULL.  It neither closes nor destroys the borrowed connection.

| st_term_session_run(session, disposition)
| Pumps until disconnect or local exit.  Writes RETURN_TO_PICKER or
EXIT_APPLICATION and returns zero, or stops at the first `IO_ERROR_*`.

| st_term_session_pump(session, disposition, finished)
| Performs one bounded connection receive and drains currently queued console
events. Polls APC audio notifications on a live connection even when suspended
or no input arrives. Once the peer has closed, drains input without attempting
asynchronous reports to the closed transport.
`finished` is always initialized false and becomes true on a terminal
condition.  Caller repeats while zero and not finished.

| st_term_session_remote_closed(session)
| True when pumping ended on a drained remote connection, not a local
hangup/exit command. NULL returns false. Read before destruction to decide
whether to show the remote-disconnect notice.

| st_term_session_prepare_disconnect(session)
| After closing the connection, delegates to CTerm's disconnect preparation
and marks the exposed row as main-display content for offline history. The
caller must remove local chrome before destruction publishes that history.
Returns zero or a negative error. Does not access the borrowed connection.

| st_term_session_send_text(session, utf8, size)
| Strictly validates and NFC-normalizes the counted UTF-8, then sends each
grapheme.  UTF-8 sessions send normalized bytes.  Legacy sessions map a
single-scalar grapheme through the configured codepage; unmappable graphemes
beep and are omitted without aborting representable neighbours.

| st_term_rip_wire_to_utf8(result, capacity, result_size, wire, size, codepage)
| Converts counted codepage wire bytes to UTF-8 without changing ASCII RIP
introducers and delimiters. `result` must have sufficient `capacity` (up to
four bytes per input byte); input and output must not overlap. On success,
`*result_size` is the byte count, with no terminator. On failure, it is
unchanged, though `result` may contain a partial conversion. NULL input is
valid only with zero `size`; NULL output is valid only with zero `capacity`
and zero `size`. Returns zero or negative `IO_ERROR_*`.
|===
