=== Approved contract and decisions

Keep Font.load(file), add Font.load(file, codepage), and return an allocated
selector or FileError/FontError. The one-argument default is CTerm.codepage at
call time, including its UTF-8 fallback; Screen.font does not determine it.
Require an actual readable File grant in the calling VM and an active terminal
with font loading support. Loading changes no assignments or settings, consumes
no grant, and leaves the File stream position unchanged.

Add Font.codepageFor(selector). Existing codepageOf(i) describes Screen.font[i]
and codepage describes its slot zero. Report actual mappings, null for unavailable
bitmaps; Codepage.encodes_ returns false for unavailable mappings.

Replace altFonts and altFont with live CTerm.font[0..3] reads/writes, in normal,
bright, blink, bright-plus-blink order. Add CTerm.setFont(selector, mask) and
CTermFontMask normal=1, bright=2, blink=4, brightBlink=8, all=15. Validate the
whole mask before updating exactly those assignments together; zero is invalid.
Keep this connected-only and independent of Screen.font's existing five slots.
Remove old declarations/dispatch without aliases. Migrate bundled callers.
The picker retains load-only registration; selecting an existing font changes
only the normal terminal assignment. Direct scripts can select loaded fonts.

File access/read errors use FileError with accurate portable/native reasons.
Expired read authority uses permissionDenied. Font-specific failures use new
FontError (code, nativeCode, message, toString), with FontErr unavailable=1,
invalidBitmap=2, unsupportedCodepage=3, noSlots=4, notLoaded=5, nativeFailure=6.
Underlying portable native status is retained, or zero for host policy failures.
Programmer errors (types, inexact/out-of-range numbers, invalid enums/indices/
masks) abort the calling Fiber. setFont returns null/FontError; indexed writes
raise that FontError using ordinary Fiber abort so assignment cannot discard it.
Failed loads publish no entry; failed selections leave all assignments unchanged.
Finish pending terminal output before selection. Existing cells retain fonts.

Record actual mappings in native catalogs. Add copied terminal metadata access
and explicit-codepage registration. Connected contexts use actual terminal
registrations/identifiers, including shared menu consoles, instead of CP437
copies. Menu/picker configured fonts retain their CP437 policy. Preserve
configured slots and skip occupied remote font selectors. Track mapping metadata
with remote variants and restore it with the registration, retaining existing
geometry/download/reset policy. Native assignment changes use one validated mask
operation. Carry failure origin rather than guessing from codes or stale errno.
Consoles own font copies; no borrowed rasters or new script resource owners.
Raw bitmap bytes, normalized host text and standard Wren semantics are preserved.

General font construction, compatibility bits and general codepage conversion
remain separate findings.

Use CMake builds and font_catalog, cterm, cterm_text, relevant Wren host/menu/
