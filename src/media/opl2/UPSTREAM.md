compatibility-mode wrapper. The original MIT license is in `LICENSE.OPAL`.

The retained operator/envelope/phase/LFO/rhythm/ROM arithmetic and linear
resampling implementation originate in that MIT Opal source. The local
reduction removes the second bank, extra channels/operators, four-operator
algorithms/pairing, extra waveforms, NEW mode, stereo/panning, OPL3 output
skew, visualizer routing metadata and buffered-write API. Upstream style
is retained around the adapted synthesis code.

New code authored for SyncTERM implements YM3812 waveform-write acceptance,
timer1 CSM key ownership, the checked native API and mono wide-sum output.
No code was copied, ported, translated or adapted from ymfm, Nuked or any
other emulator. Other emulators were behavioral references only. Control
expectations use the independently recorded BIG reference17/18 observations
and register contracts. In particular, WSE gates E0 write acceptance: clearing
it retains the last accepted waveform. CSM adds one independent key pulse
on timer1 overflow, including masked overflows, and releases only that key
contribution; normal melodic/rhythm keys survive it.

## Native execution profile

The caller owns a pointer-free bounded value and serializes register writes,
status reads and rendering. There is no device, bus/interrupt emulation,
foreign system clock, write-spacing queue, allocation or thread. Timers and
CSM advance on generated native samples: timer1/2 tick every4/16 nominal
49716-Hz native frames using carried frame phase. Timer bit7 resets status
without replacing low control bits. This is local synthesis timing, not
asynchronous chip bus/scan timing. The declared status-port profile reads
unused low bits as06; BIG detection uses only e0. Undocumented silicon test/
debug-pin effects and bit-identical analog/canonical-PCM behavior are outside
this native functional profile.

The output is a signed32 mono amplitude sum. Individual operator output is
about12-bit amplitude; the full18-operator additive sum remains unclipped.
The native BIG audio owner applies fixed source gain3.25718 and duplicates mono
into wide stereo before existing channel0 gain, mixer summation and final
signed16 conversion. This preserves polyphonic headroom. The one-time gain
measurement and playback tests belong to BIG integration; this component
alone makes no audible-device claim.

`big_opl2` has independently authored expectations for waveform-write
retention, all18 operator slots and9 channels, ignored holes/OPL3 stereo bits,
rejected extended-bank accesses, rhythm and melodic key ownership, timer
masks/reset/cadence, masked CSM state and actual PCM, four waveform extrema,
full additive positive/negative headroom, partition/state identity, silence,
reset and checked errors. Expected extrema are explicitly calculated from
ROM peak arithmetic, not generated by the emulator under test. The focused
application license test traverses the normal Settings > Licenses UI and
compares the complete visible notice, including its scroll tail, against the
checked-in MIT text. Physical audio/MIDI are disabled.

BIG b/n/N and actual X7 callback publication are integrated by CTerm. This
library remains independent of music-buffer allocation and ?2 availability;
see [BIG implementation](../../../docs/BIG_IMPLEMENTATION.adoc) for the native
owner, channel routing, fixed gains and lifecycle verification.
